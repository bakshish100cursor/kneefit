# Install on Android
1. Create a free public GitHub repository, upload ALL files and the icons folder, enable Settings > Pages (deploy from main branch, root).
2. Open https://YOURNAME.github.io/REPO/ in Chrome on your phone.
3. Three-dot menu > Install app / Add to Home screen.
Alternatives: Netlify Drop, or pwabuilder.com for an APK. Quick test: open index.html from the phone's files in Chrome (no install).
If you already installed v1, open the app online once so it updates; your saved data stays.
Data lives on the phone only; use Data / backup > Export regularly.
